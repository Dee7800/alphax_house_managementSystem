HOUSE MANAGEMENT SYSTEM

Project Whitepaper & Technical Audit Documentation

Engineered by: ENG. GIDEON AMBIYIA

1. Product Vision & User Roles

The House Management System is an enterprise-grade solution designed to centralize and secure the complex ecosystem of real estate management. The system operates on a Dual-Role Architecture:

Level 1: Global Administrator

Responsible for platform health, security audits, landlord onboarding, and high-level system configurations. Features include the Credential Vault and Global Security Logs.

Level 2: Landlord (Local User)

Optimized for property-specific tasks: tenant lifecycle, automated rent collection, vacancy tracking, and direct financial reporting.

2. Database Architecture: Step-by-Step
Step 1: Relational Data Modeling

Data is structured using normalized JSON objects for Tenants, Landlords, Payments, and Vacancies, ensuring high scalability.

Step 2: Secured Local Persistence

An encrypted LocalStorage layer provides sub-second data retrieval and full offline capability, serving as a reliable cache.

Step 3: Asynchronous Cloud Sync

Integrated with Supabase (PostgreSQL), the system performs real-time background syncing to ensure zero data loss across devices.

3. The Reporting Engine

Our custom reporting engine transforms complex JSON data into professional PDF documents. Using the jsPDF and AutoTable protocols, the system calculates totals, shortfalls, and balances in real-time, providing landlords with audit-ready statements at the click of a button.

4. Why Choose This System?

• Resilience: Dual-layer storage (Local + Cloud) means your data is never unreachable.
• Security: Brute-force protection and role-isolated data scoping prevent unauthorized access.
• Speed: No bloated frameworks—built with pure JS for maximum performance.
